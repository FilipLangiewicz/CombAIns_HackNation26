Technologie i uruchomienie

Python 3.13

Zablokowane wersje pakietów. Instalacja jednym poleceniem pip.

pip install -r requirements.txt
python main.py

Docker Compose

Dwie usługi: GUI w przeglądarce i CLI dla folderu input/.

docker compose up
docker compose run --rm cli

Tylko open source

pypdfium2, RapidOCR z ONNX Runtime, PyYAML, NumPy. GUI używa tylko biblioteki standardowej.

Praca lokalna

Bez API, bez klucza i bez internetu. Dane osobowe z dokumentów nie opuszczają komputera.

Moduły

Odczyt, OCR, klasyfikacja, ekstraktory, walidacja, CLI i GUI. Każdy moduł ma jedno zadanie.

src/odw2json/ · config/types/

Jakość

268 testów automatycznych. Dokumentacja architektury, reguł i dodania nowego typu. Dziennik pomiarów F1.
